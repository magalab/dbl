# ADR 0005: SQL 查询工作区标签

- 状态：工作区与可选查询历史首版已实现；桌面人工验收待完成
- 日期：2026-10-25

## 决策

- 每个查询工作区拥有独立 SQL 编辑器状态、当前结果窗口、结果列、结果来源文件、排序状态、导出路径和查询历史；SQLite 连接由所有标签共享。
- 当前进程最多创建 16 个查询工作区，至少保留一个标签。编辑器与结果状态不持久化。查询历史默认只驻留内存；用户在历史面板明确开启后，最多持久化最近 100 条 SQL/时间/行数/耗时/粗粒度结果状态，单条 SQL 上限 64 KiB，并沿用设置文件的 `0600` 权限。错误详情不写入历史。关闭开关会从设置文件删除历史；历史面板也可清理当前工作区或全部历史。
- 同一时刻只允许一个活跃结果游标。切换或关闭持有未读取结果的标签时，取消并关闭游标，保留已读取结果并在状态栏提示其余行已停止。这样避免多个隐藏游标占满 SQLite 的连接池。
- 每个结果集记录其连接身份；导出必须针对产生该结果集的连接运行。若当前活动连接与结果来源不同，导出按钮禁用，避免把旧 SQL 静默重跑到另一数据库。SQLite 比对规范化文件身份，远程 SQL 连接比对 profile ID。
- SQLite 导出在独立只读连接上运行并通过 authorizer 限制写操作；PostgreSQL 导出通过独立连接和只读事务执行。所有 SQL 导出都是重新执行原查询，可能因非确定性 SQL 或并发写入而与当前窗口不同。
- CSV/JSON 先写入目标目录下权限为 `0600` 的临时文件；完成后同步文件并以原子且不覆盖目标的方式发布。失败或取消只清理临时文件，崩溃时不会留下以正式目标名显示的半成品；若发布已完成但目录同步失败，界面明确提示文件已生成但掉电持久性不确定。
- SQL 写操作和风险分类不明确的语句在所有可写环境中执行前都需确认；对话框列出环境、驱动、连接、当前选中对象、风险估计和完整语句。分类为简单读取类的语句可直接执行；函数/括号表达式、锁、事务控制、变量赋值、多语句等保守归为未知并触发确认。
- 标签上限和编辑器状态管理属于应用壳层；数据源连接生命周期仍由 connection capability 管理，不将一个 SQL 编辑器标签视作一条独立物理连接。

## 验证

- 主包单测覆盖编辑器和结果窗口跨标签隔离、切换恢复、关闭非活动标签、至少保留一个标签及 16 标签上限。
- UI tester 覆盖 1440px 宽窗口显示检查器、900px 窄窗口自动收起检查器且仍保留 SQL 编辑器。
- MyGo 主窗口关闭回调会取消 SQL 游标、导出、Redis/Mongo/etcd 与 AI 请求，并关闭当前 connection manager 连接；主包测试验证所有任务 context 取消、连接进入断开状态且 mock adapter 已关闭。
- `sqlstream.Cursor` 将 batch read、on-finish 与 close 操作串行化；取消查询上下文后再关闭游标，避免应用退出或标签切换时与 `NextBatch` 并发改写游标状态。
- UI 人工验收仍需在依赖可构建的桌面环境完成，特别是焦点保留、正在读结果时切换/关闭和不同数据库来源导出保护。

## 限制

- 标签与结果在应用重启后不恢复；未启用本机历史保存时，查询历史只在当前进程存在。启用后，重启时的历史恢复到首个查询工作区。
- 切换标签会停止当前未读取的结果游标，不支持在多个标签间并行读取。
- PostgreSQL adapter、真实 PostgreSQL 17 服务及 profile 私有 CA `verify-full` TLS 集成都已验证；当前剩余工作是桌面 UI 的人工验收，见发布准备清单。
