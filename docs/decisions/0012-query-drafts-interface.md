# ADR 0012: 可选 SQL 草稿恢复与界面偏好

- 状态：已实现；原生窗口启动模式与系统字体的跨平台人工验收待完成
- 日期：2026-11-18

## SQL 草稿

- 设置 → 常规中主动开启，默认关闭，与查询历史开关独立。只保存 SQL 查询标签的内容、标题、顺序、当前 SQL 标签、连接身份和数据库 / Schema 引用，不保存结果、数据 / 结构编辑草稿或活动连接。
- 启动恢复时不访问数据库、不执行 SQL。连接已删除或 SQLite 文件不存在时保留内容，仍可切换与编辑；有匹配的已保存连接时可手动重新连接。连接其他数据库不会自动改绑已有连接引用的 SQL 草稿。
- 主线程通过编辑器 buffer version 和标签元数据观察变更，停止变化约 750 毫秒后获取快照，后台保存。退出前同步补存；可取消的正常关闭若保存失败会保持窗口并提示错误，可修复后重试或在设置中关闭草稿保存。强制结束进程或系统会话结束不承诺保留最后一次自动保存后的输入。
- 最多保存 16 个标签，单条 SQL 不超过 256 KiB，超限不截断，编辑器显示不保存提示。关闭标签移除其草稿；关闭自动保存原子清空磁盘草稿，不删除当前编辑器内容。首版不提供版本历史、关闭标签找回或跨设备同步。
- 草稿以明文写入仅当前用户可访问的 `settings.toml`，复用设置的原子替换和权限策略；界面明确提示 SQL 可能包含敏感值。连接只保存引用 / 本地文件路径，连接密码、API key 与 TLS 私钥继续仅通过凭据库保存。
- 草稿更新在 store 锁内合并当前设置，并使用独立 revision 防止迟到的旧保存覆盖新快照或恢复已清除草稿。

## 界面设置

- 设置 → 界面提供普通窗口（默认）、最大化、全屏三种启动模式，通过 MyGo WindowOptions 设置，下次打开应用时生效。
- 界面字体、字号与编辑器字体、字号独立配置；字体从本机已安装字体选择，编辑器优先列出等宽字体。默认保留系统界面字体和编辑器的系统等宽字体，缺失字体由系统回退。
- 选择时提供预览，点击保存后即时应用于主窗口和设置窗口；编辑器字体用于 SQL 和 MongoDB / etcd JSON 编辑器。恢复默认先重置设置页的选项，再点击保存生效。

## 验证

- 偏好设置测试覆盖中文 / 空 SQL 往返、独立更新合并、旧保存屏障、关闭清空、内容上限及不合法字体 / 启动值处理。
- 应用测试覆盖标签筛选与恢复、未连接标签切换、连接归属保护、关闭标签移除、退出补存和失败返回、中英文设置入口及字体分别应用。
- macOS / Windows 的全屏与最大化启动、原生字体选择和较大字号的完整交互仍需实机验收。
