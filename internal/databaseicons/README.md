# Database brand marks

The SVG marks in `assets/` are copied from the [Simple Icons](https://github.com/simple-icons/simple-icons) v15 icon set. The project is released under CC0 1.0; that does not grant rights to use the underlying brand names or trademarks. These marks are used only as compact driver identifiers in the connection tree, with each database name shown beside its mark.

Files: SQLite, PostgreSQL, MySQL, Redis, MongoDB, and etcd.

The names and marks remain the property of their respective owners. See the [PostgreSQL logo page](https://wiki.postgresql.org/wiki/Logo) and the [brand resources for MySQL](https://www.mysql.com/about/legal/logos.html), [Redis](https://redis.io/wp-content/uploads/2024/09/Redis_BrandGuidelines_Partners_Vol01_20240903_SM.pdf), and [MongoDB](https://www.mongodb.com/company/newsroom/brand-resources) for their respective usage guidance.
